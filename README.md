# Repo X-Ray 🔎

**Рентген Python-проєкту: карта імпортів, вихідний код і потенційний вплив змін.**

Локальний CLI створює автономний інтерактивний HTML-звіт. Без API-ключів,
пакетів pip, зовнішніх скриптів, серверів та виконання коду аналізованого проєкту.

## Запуск за хвилину

Потрібен Python 3.10+. Розпакуйте архів та відкрийте термінал у папці `repo-xray`:

```bash
python3 xray.py examples -o demo.html
```

Відкрийте `demo.html` у браузері. У Windows замість `python3` можна використовувати `py`.
Готовий приклад також є у `demo.html` всередині архіву.

### Власний локальний проєкт

```bash
python3 xray.py /path/to/project -o report.html --json report.json
```

### Публічний GitHub-репозиторій

Потрібен встановлений Git та доступ до мережі:

```bash
python3 xray.py https://github.com/OWNER/REPO -o report.html
```

Замість OWNER/REPO вкажіть потрібного власника та репозиторій. Завантажується поточна
основна гілка через shallow clone, тимчасова копія видаляється після аналізу.
Для приватних репозиторіїв використовуйте власну локальну копію.

## Можливості

- Python AST: звичайні й відносні імпорти, типовий `src/` layout.
- Інтерактивна карта: стрілка означає «імпортує».
- Пошук файлів, прямі залежності та зворотні зв’язки.
- Режим «Вплив змін» обходить зворотні залежності, включно з циклами.
- Пошук функцій, класів, `__main__.py` та стандартного main guard.
- Вихідний код із номерами рядків, перелік зовнішніх / нерозпізнаних імпортів.
- Попередження про синтаксичні помилки та неоднозначні модулі.
- Самодостатній HTML, який працює офлайн, та необов’язковий JSON.

## Межі першої версії

Це карта **імпортів**, не граф викликів функцій і не повний аналіз потоків даних.
Динамічні імпорти, runtime-плагіни, зміни `sys.path`, інші мови та нестандартні
корені пакетів не підтримуються. Імпорти в умовних блоках, зокрема TYPE_CHECKING,
враховуються як можливі зв’язки. Вплив змін — припущення за імпортами, не доказ поломки.
Точки запуску з конфігурації packaging поки не читаються.

До 2000 Python-файлів, до 500 KB на файл; карта відображає до 80 вузлів за раз.
Для великих репозиторіїв аналізуйте підпапку. Символічні посилання та стандартні
папки залежностей пропускаються. HTML/JSON містить код, у якому можуть бути секрети:
перевіряйте звіт перед публікацією. Локальний аналіз не передає код у мережу.
GitHub-завантаження виконує Git; використовуйте актуальну інсталяцію Git.

```bash
python3 -m unittest discover -s tests -v
```

GitHub Actions запускає тести на Python 3.10 та 3.12.

## Публікація у власному GitHub

Створіть порожній репозиторій `repo-xray` у своєму GitHub, потім у цій папці:

```bash
git init
git add .
git commit -m "Initial Repo X-Ray MVP"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/repo-xray.git
git push -u origin main
```

Замініть YOUR_USERNAME на свій логін. Потрібна авторизація GitHub.
Архів не означає, що репозиторій уже опублікований.
